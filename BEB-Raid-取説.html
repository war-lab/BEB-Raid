ビーブレイド

通勤電車のスキマ時間で TOEIC L&R を鍛える、オフラインファーストの学習アプリ。 静かに続く学習と、少し賑やかな報酬を、夜行列車の世界観で。

STEP 1

はじめかた（初回診断）

最初に 30問の診断（リスニング15問・リーディング15問）で今の実力レートを推定します。

時間がなければ 自己申告のTOEICスコアを入力してスキップしてもOK。あとから診断し直せます。

ヒント: ブラウザの「ホーム画面に追加」でインストールすると、オフラインでもすぐ起動でき、学習データが消えにくくなります。

HOME

ホーム画面の見かた

上から順に、いま自分がどのシーズン／レイドにいるか、直近4週間の学習ヒートマップ、そして本日の学習導線が並びます。

  • 今日のクエスト（金のボタン）— 迷ったらここを押すだけ。アプリが今やるべき問題を自動で組みます。
  • クエストの長さ— 3分 / 7分 / 15分 から通勤時間に合わせて選択。
  • モードタイル— 特定の練習を単独でやりたいときに選びます（下記）。Part2瞬発・Part5・語彙SRS・シャドーイングに加え、じっくり読解（Part7）も独立したタイルから始められます。
  • 間違えた問題— 過去に間違えた問題だけをまとめて振り返れる一覧への入口です（下記）。
PART 2 / 5

ドリル（Part2瞬発・Part5）

Part2瞬発は音声を聞いて即答するリスニング。1問目は「音声を再生」をタップ、2問目以降は自動で音声が流れます（設定でOFFにできます）。3択から選ぶだけで片手・短時間で回せます。

Part5は文法・語彙の穴埋め。上部の細い進捗バーと英字タグ（PART 2 など）で今どこを解いているかが分かります。

正誤は枠の色と ✓ / ✕ の両方で示すので、色が見分けづらい環境でも判別できます。復習カードの「間隔について」や、結果画面の「当て勘」「速度不足」はタップすると意味の説明が開きます。

VOCAB

語彙SRS（仕分け・復習）

単語・フレーズを 「知ってる / 知らない」でサクサク仕分けし、忘却曲線に沿って復習に出します。仕分けは 20語ずつの区切りで進み、1区切り終えるたびに続けるか一息つくかを選べます。

カード上部の ランク（S / A / B / C）は出題頻度の目安（Sが最頻出）。誤答した語は後日きちんと復習に戻ってきます。

ランクや、復習時の自己評価（もう一回 / OK / 余裕）はタップすると意味の説明が開きます。選んだ直後なら取り消せるので、慌てて押しても大丈夫です。

SHADOWING

シャドーイング

お手本音声に続いて発話する練習。再生 / 3秒戻し / 次の素材で自分のペースに合わせられます。

  • 速度— 0.7x / 0.85x / 等倍 / 1.15x / 1.3x（ピッチは保ったまま変速）。1.15x以上はリスニングの段階が上がると選べるようになります。
  • 表示— 非表示 / 英文 / 英文+和訳 を切り替え。慣れたら英文を消して耳だけで挑戦。
DASHBOARD

進捗をみる（ダッシュボード）

予測スコア帯・伸びグラフ・弱点マップで学習の効果を確認します。

データが少ないうちは「計測中」と正直に表示されます（伸びグラフは2件以上、弱点マップは各タグ5問以上、スコア帯は14日分たまると表示）。焦らず続けるほど精度が上がります。

読解のペース（Part7の1問あたりの所要時間と目標ペースとの差）も表示され、時間切れで解き切れていないかの目安になります。

実試験・IPテストのスコアを日付とL/Rの点数（各5〜495点）で登録すると、予測帯との差を確認できます。登録済みのスコアはあとから編集・削除できます。

SETTINGS

設定でできること

  • イヤホンなしモード— リスニング問題をリーディング系に差し替え（電車で音を出せないとき）。
  • テーマ— OS追従 / ダーク / ライト。文字サイズ— 英文問題文を S / M / L で調整。
  • ハプティクス— 正解確定時に軽く振動。
  • 誤タップの取り消し猶予— 選択直後に取り消せる機能のON/OFF（既定ON）。
  • 音声の自動再生— Part2瞬発で2問目以降にタップなしで再生する機能のON/OFF（既定ON）。
  • キャッシュ / 永続化— 使用量の確認と削除（削除前に確認ダイアログが出ます。解答履歴などの学習データには触れません）。ホーム追加で永続化されやすくなります。
  • AIに聞く（BYOK）— 自分のAIサービスのAPIキーを設定すると解説を生成できます。キーは端末内にのみ保存され、外部には送信されません。削除する際は確認ダイアログが出ます。
  • エクスポート / インポート— 学習データの書き出しと復元。復元は対象のデータと件数を確認してから実行します。

読解（Part7）

  • ホームのモードタイルに「じっくり読解」という独立の入口があり、Part2瞬発・Part5と同じようにパッセージ数を選んで単独で始められます。
  • ダッシュボードに読解のペース（1問あたりの所要時間と目標ペースとの差）が表示され、時間切れで解き切れていないかの目安になります。

間違えた問題一覧

  • ホームの「間違えた問題」から、過去に間違えた問題だけの一覧を開けます。
  • 各問題は「解説」を開くまで正解を表示しません（先に見えると解き直す価値が下がるため）。件数が多いときは「もっと見る」で少しずつ表示します。
  • 一覧からそのまま復習セッションとして解き直せます。

イベントバトル

  • 複数人でリアルタイムに同じ問題を解く対戦モード。音声の問題は主催者（ホスト）が再生をタップしてから流れるため、会場全体で音がずれません。
  • 終了後はその場で誤答した問題を復習できます（あとから「間違えた問題」で開くこともできます）。
  • 通信に失敗しても再試行できます（ルームコードの誤りかオフラインかの見分けも表示されます）。

オフラインとデータの扱い

  • 解答と復習の記録は その場で端末内（IndexedDB）に保存。電波が無くても学習は正常に進みます。
  • iOSではストレージ退避でデータが消えることがあるため、ホーム画面への追加と、設定からのエクスポートを保険にしてください。
  • 共有サーバーが落ちても、ひとりで解く機能は一切影響を受けません（設計上の大前提）。

レイド（みんなで倒す）

  • 週替わりのボスに、日々の学習で稼いだダメージをぶつける協力イベント。
  • サーバーに送るのは 表示名とダメージ換算値だけ。正誤の中身・レートの実値・本名や社名は端末の外に出ません。
  • 最新情報の取得に失敗しても再試行できます（オフラインかサーバー障害かの見分けも表示されます）。
  • ボス役に立候補すると、高難度セットの正誤がその週のゴーストボスの弱点になります。開始前に同意画面で共有内容を確認し、送信後もいつでも撤回できます（撤回は確認のうえサーバーから即時削除され、元に戻せません）。
BEB RAID かんたん取説 — 画面はダークテーマ・モバイル表示の例です。
実際の表示はテーマ設定・端末・学習の進み具合で変わります。
操作に迷ったら、ホームの「今日のクエスト」を押すだけでOK。
