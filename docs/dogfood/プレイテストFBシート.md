# プレイテストFBシート（外部プレイヤー向け）

対象: 発起人以外でプレイに参加してくれる方（5〜10名想定）。
タイミング: **使い始めて3日目くらい**と**1〜2週間使った後**の2回に分けて聞くのが理想（初見の違和感と、続けた上での感想は別物なので）。

個別の問題文・解説・音声の不具合は、このシートではなく [Issue: 悪問メモ](../../.github/ISSUE_TEMPLATE/bad-question.md) へ都度投げてもらう方が拾いやすい。このシートは「体験全体」についてのFB用。

---

## 1. 初回体験（最初の5分）

- [ ] ホーム画面追加までスムーズにできた
- [ ] 起動〜最初の問題が出るまで迷わなかった（P0診断の意図が分かった）
- [ ] 「これは自分のレベルに合っている」と感じた診断結果だった
- [ ] 3秒以内に起動した体感があった

一番つまずいた・迷ったポイントは？（自由記述）

---

## 2. 毎日使う部分（電車ソロコア）

- [ ] クイックパック（3/7/15分）の時間の感覚は実際の所要時間と合っていた
- [ ] 語彙SRS（フレーズ・音声・4択復習）はテンポよく回せた
- [ ] Part2瞬発・Part5ドリルの難易度は「今の自分」に合っていた（簡単すぎ/難しすぎならどちらか明記）
- [ ] 誤答した単語が後で復習に出てくる感覚があった（key単語循環）
- [ ] レート・伸びグラフ・ストリークは「続ける理由」になっている

---

## 3. M2の新機能（リスニング・カリキュラム）

- [ ] ディクテーション（穴埋め）の難易度・テンポは適切だった
- [ ] シャドーイングのカラオケハイライトは見やすく、実際の発話についていけた
- [ ] 先読みトレーナー（Part3/4）の秒数は妥当だった（短すぎ/長すぎならどちらか明記）
- [ ] 「今日何をやるべきか」がホーム画面を見れば分かった（アプリが決めてくれている感覚）
- [ ] フェーズ・シーズンの進み方に納得感があった
- [ ] 予測スコア・到達予測の表示は参考になった
- [ ] AIに聞く機能（BYOK設定した場合のみ／⚠️実キーでの動作確認が誰もまだ済んでいない機能。あなたが試すのが実質初の実動作確認になる可能性が高い。エラーが出た・回答がおかしい・課金が想定と違う等あれば真っ先に共有してほしい）

---

## 4. コンテンツ品質（全体の印象）

- [ ] 英文は自然だと感じた（不自然だった問題があれば悪問Issueへ）
- [ ] 音声は聞き取りやすかった（機械音声特有の違和感の有無）
- [ ] 和訳・解説は分かりやすかった
- [ ] 同じような問題ばかりで飽きる、と感じた場面があった

---

- 明日もやりたいと思うか: 思う / どちらとも言えない / 思わない
- そう思う・思わない理由（自由記述）:

- 一番使わない・邪魔だと感じた機能は？:
- もし友人に勧めるなら何点か（0〜10）:

## 回収方法（発起人側メモ）

- このMarkdownをコピーして各自に埋めてもらう、またはGoogleフォーム化してもよい
- 個別の悪問報告はIssueに寄せ、このシートには集約しない（悪問Issueが埋もれるため）
- 回収したFBは docs/STATUS.md か本ファイル末尾に集計メモを追記していく運用でよい
