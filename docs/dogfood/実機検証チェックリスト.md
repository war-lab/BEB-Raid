# 実機検証チェックリスト（T-36 / T-40のAI支援範囲）

正本: 08のT-36行、01の非機能要件、05の8節、docs/08 5.1節。各項目は「手順（何をタップし何を見るか）」と「期待結果」のペアで記述する。iOS Safari・Android Chromeの両方で確認する。

## 準備

1. 実機のブラウザで対象のURLを開く。公開URL（`https://war-lab.github.io/BEB-Raid/`）へのデプロイは main への push でのみ走るため、**dev に統合済みで main へ未マージの変更を確認したい場合は公開URLを使わない**。その場合はローカルで `npm run build -w @beb-raid/app` してから `npm run preview -w @beb-raid/app` を起動し、同一LANの実機からそのアドレスを開く。
2. ホーム画面に追加する（iOS: 共有→ホーム画面に追加／Android: メニュー→ホーム画面に追加）。
3. 追加したアイコンから起動する（以降は standalone 起動での確認）。

## 1. standalone起動・3秒起動

| 手順 | 期待結果 |
|------|---------|
| ホーム画面のアイコンをタップして起動する | ブラウザUI（アドレスバー等）が表示されず、アプリ然とした画面で開く（standalone表示） |
| 起動からストップウォッチで計測し、「今日のクエスト」ボタンをタップ可能になるまでの時間を測る | 3秒以内にタップ可能な状態になる（2回目以降のキャッシュ済み起動で計測） |
| ホーム画面のアイコンを目視する | 小サイズでもロゴが視認できる（T-02の持ち越し項目） |

## 2. 音声自動再生制限

| 手順 | 期待結果 |
|------|---------|
| Part2瞬発（通常モード）を起動し、最初の問題で再生タップする | 1問目は再生タップが必要（unlock） |
| 続けて2問目・3問目と進める | 2問目以降は再生タップを要求されず、自動的に音声が流れる（iOS Safariの自動再生制限が最初の1回のunlockで解除されている） |
| 冒頭再生モード（特訓）でも同様に確認する | 同様に2問目以降は自動再生される |

## 3. 機内モード動作

| 手順 | 期待結果 |
|------|---------|
| オンライン状態で一度ホーム画面を開き、設定画面の「キャッシュ使用量」が増えなくなるまで待つ（パック自動ピン留めの完了を待つ。進捗表示は未実装のため使用量で判断する） | - |
| 機内モードをONにする | - |
| アプリを再起動し、「今日のクエスト」→セッション完走→リザルトまで進める | ネットワークエラーが一切表面化せず完走できる |
| 語彙SRS画面を開き、カードに解答してからフレーズ音声を再生する（復習モードのフレーズ音声は解答後にしか出ない。解答前に流すとリコールテストにならないため） | 機内モードでも音声が再生される（PackCacheキャッシュ済み） |
| 機内モードのままダッシュボードを開く | エラーなく表示される |

## 4. 中断・再開

| 手順 | 期待結果 |
|------|---------|
| クイックパック（7分等）を開始し、2問ほど解答する | - |
| アプリを完全に終了する（タスクキルまたはブラウザタブを閉じる） | - |
| ホーム画面のアイコンから再度起動する | ホームに「続きから再開（残りN問）」が出る（自動では再開しない） |
| 「続きから再開」をタップする | 同じセッションの続き（3問目）から再開する |
| 解答済みの2問分がやり直しにならないことを確認する | 既存の解答ログが失われていない |

## 5. キャッシュ使用量（T-23 / T-35持ち越し）

| 手順 | 期待結果 |
|------|---------|
| 設定画面のキャッシュ使用量表示を確認する | 0ではなく、実際にキャッシュされたパック・音声の合計に近い値が表示される |

## 6. 語彙SRS 4択リコールテストの操作感（T-19/T-21改訂の持ち越し）

| 手順 | 期待結果 |
|------|---------|
| 語彙SRS復習モードでカードを1枚進める | フレーズ中の対象語が強調表示され、「この単語の意味は？」の4択が表示される |
| 4択のいずれかをタップする | 正誤が明示され、続けて自己評価3段階（もう一回/OK/余裕）に進む |
| 操作感に違和感がないか確認する（タップ目標のサイズ・反応速度） | 違和感があれば具体的に記録する |

## 7. ライトテーマ実地確認（T-03持ち越し）

| 手順 | 期待結果 |
|------|---------|
| 設定画面でテーマをライトに切り替える | 文字色・背景のコントラストが屋外光下でも視認できる |

## 記録方法

各項目の結果（OK / NG / 保留）と気づいた点は本ファイル末尾か `docs/history/` の該当月へ「実機検証メモ」として残す（STATUS.mdは「現在地のみ・300行以内」の方針で、個別タスク行は残していない）。NGがあれば Issue 化して修正タスクにする。
