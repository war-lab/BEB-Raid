## コンセプト（1行）

**主戦場は通勤電車。** 1タップで始まる弱点駆動ドリルと金フレ型語彙をオフラインPWAで回し、誤答はすべて復習デッキへ。週次レイドボス（協力PvE／上級者ゴーストとの非対称PvP）が「ひとりの継続」に社会性を接ぎ木し、昼休みの同期バトルは週イチのお祭りとして開催する。

## 設計の3本柱

1. **電車ソロの学習ループが本体** — 3分から始められ、オフラインで動き、全解答ログから弱点駆動で出題する。380→760 のスコア倍増は「何を捨てて何をやるか」の選択が9割で、それをアプリが代行する。誤答の key 単語から次の学習が自動生成される。
2. **統一レイドエンジンがレベル差と孤独を同時に解決する** — ボスは「HP＋防御パターン＋攻撃イベント」のデータ構造。中身がアプリ生成なら協力PvE、人間の解答記録なら非対称PvP（ゴーストレイド）。ダメージは常にハンディキャップ換算なので、300点にも900点にも役割がある。
3. **コンテンツは自作＋TTSで静的配信** — 市販教材・金のフレーズの流用は著作権リスクがあるため（01参照）、LLM生成＋人手レビュー＋TTS音声のパイプラインで量産し、GitHub Pages から静的配信する。アプリ本体はサーバーレスで動き、共有が必要なレイドだけ極小APIを使う。
